# PromptHub AI

PromptHub AI is a production-ready Next.js 15 SaaS-style prompt discovery website for AI image prompts. It includes a premium dark UI, Firebase Authentication, Firestore data model, seeded prompt data, search, prompt details, likes, favorites, profiles, dashboards, SEO routes, and Vercel-ready deployment configuration.

## Tech Stack

- Next.js 15 App Router
- React 19 + TypeScript
- Tailwind CSS with glassmorphism and neon design tokens
- Firebase Authentication with email/password, Google sign-in, and password reset
- Firestore Database with security rules
- Framer Motion animations
- Sonner toast notifications

## Features

- Landing page with hero, search, featured prompts, trending prompts, new prompts, categories, prompt of the day, and footer
- Explore page with category filters, sorting, suggestions-ready search, and load-more infinite browsing behavior
- Prompt details page with copy, like, favorite, share, author card, tags, view metrics, and similar prompts
- Authentication pages for sign up, login, Google sign-in, and forgot password
- User dashboard with prompts, favorites, profile settings, stats, and likes received
- Admin dashboard with user management, prompt management, feature/delete controls, and site analytics cards
- Leaderboard, user badges, follow creator UI, recently viewed schema support, and creator stats
- SEO metadata, Open Graph metadata, sitemap.xml, robots.txt, and structured data
- 720 deterministic sample prompts generated by category, including 100+ each for Anime, Fantasy, Realistic, Minecraft, Wallpapers, and Logos

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## Firebase Setup

1. Create a Firebase project.
2. Enable Authentication providers:
   - Email/password
   - Google
3. Create a Firestore database.
4. Copy your web app config into `.env.local`:

```bash
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

5. Deploy Firestore rules:

```bash
firebase deploy --only firestore:rules
```

6. Seed Firestore with the bundled production-quality sample data:

```bash
FIREBASE_SERVICE_ACCOUNT='{"type":"service_account",...}' npm run seed
```

The seed script writes users and 720 prompts to `users` and `prompts` collections.

## Firestore Collections

### users

```ts
uid: string
username: string
email: string
avatar: string
role: 'user' | 'admin'
createdAt: Timestamp
```

### prompts

```ts
id: string
title: string
content: string
category: string
authorId: string
authorName: string
likes: number
favorites: number
views: number
tags: string[]
createdAt: Timestamp
featured: boolean
promptOfDay: boolean
```

Additional subcollections support likes, favorites, following, and recently viewed prompts.

## Deployment to Vercel

1. Push this repository to GitHub.
2. Import it in Vercel.
3. Add the environment variables from `.env.example`.
4. Set `NEXT_PUBLIC_SITE_URL` to your production URL.
5. Deploy.
6. Run the seed command locally or in a secured CI job with `FIREBASE_SERVICE_ACCOUNT`.
